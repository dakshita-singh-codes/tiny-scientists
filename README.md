# 🔬 Tiny Scientists

> Turning curiosity into discovery, one tiny scientist at a time.

Tiny Scientists is an interactive STEM learning platform designed to make science fun and engaging for children through games, animations, quizzes, stories, and hands-on learning experiences.

---

## 🌟 Features

### 🚀 Interactive Learning
- Visual lessons on science concepts
- Animated explanations and storytelling
- Learn through exploration instead of memorization

### 🎮 Gamified Experience
- Quizzes and challenges
- XP points and rewards system
- Fun activities to reinforce learning

### 🌍 Science Topics Covered
- Solar System
- Animals and Habitats
- Human Body
- Plants and Nature
- Earth and Environment
- Future STEM Modules

### 🤖 SciBuddy AI Assistant
- Answers students' questions
- Encourages curiosity and self-learning
- Makes learning more interactive

### 🌐 Accessibility Features
- Kid-friendly UI
- Responsive design
- Multilingual support
- Read-aloud functionality

---

## 🛠️ Tech Stack

**Frontend**
- React.js
- TypeScript
- Vite
- Tailwind CSS

**Backend**
- Node.js
- Express.js

**Other Tools**
- Gemini API (for AI-powered assistance)

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/dakshita-singh-codes/TinyScientists.git
cd TinyScientists
```

### Install dependencies

```bash
npm install
```

### Run locally

```bash
npm run dev
```

Open:

```txt
http://localhost:3000
```
### or click on this link to open 

https://tiny-scientists.vercel.app/
